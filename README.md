# Personal Website

Welcome to my personal website! This site is a showcase of my skills, projects, and experiences, built with the help of [Raja Prerak](https://github.com/rajaprerak).

## Features 📋
- ⚡️ **Fully Responsive**: Works seamlessly on all devices.
- ⚡️ **Valid HTML5 & CSS3**: Ensuring modern and clean code standards.
- ⚡️ **Typing Animation**: Implemented using [Typed.js](https://github.com/mattboldt/typed.js).
- ⚡️ **Easy to Modify**: Flexible and straightforward to update content.

## Sections 📚
- ✔️ **About**: A brief introduction about me.
- ✔️ **Interests**: My hobbies and passions.
- ✔️ **Education**: Academic achievements and qualifications.
- ✔️ **Online Certification**: Relevant certifications and courses I've completed.
- ✔️ **Experience**: Work experience and roles I've undertaken.
- ✔️ **Projects**: A showcase of my key projects.
- ✔️ **Skills**: Technical and soft skills I possess.
- ✔️ **Resume**: A downloadable version of my resume.
- ✔️ **Contact Info**: Ways to reach out to me.

## Tools Used 🛠️
- **GitHub Pages**: Hosting the static website using [GitHub Pages](https://pages.github.com/).
- **HTML, CSS, JS**: Core technologies used for building the site.
- **Typed.js**: Adding dynamic typing animations for a modern touch.
